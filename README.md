# Checkpoint 02 — Soluções em Energias Renováveis e Sustentáveis

Este repositório contém a entrega do **Checkpoint 02** da disciplina de *Soluções em Energias Renováveis e Sustentáveis* (1CC / 2º Semestre). 

O projeto consiste na integração de dados provenientes de duas APIs públicas (SIGA/ANEEL e Open-Meteo) para a aplicação de algoritmos de **Aprendizado de Máquina (Machine Learning)** em Python, contemplando tarefas independentes de **Classificação** e **Regressão**.
